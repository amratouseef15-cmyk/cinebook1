# 🎬 Cinebook - Movie API

Cinebook is a RESTful Movie API built using **Node.js** and **Express.js**.  
The project provides APIs to retrieve movie information and showtime details using a simple and organized backend structure.

---

## 📌 Project Overview

Cinebook is designed as a backend application for a movie-booking or movie-management system.

The application stores movie information and showtime data and provides REST API endpoints to access them.

The project follows a modular structure using:

- Express.js for the web server
- Controllers for application logic
- Routes for API endpoints
- Data files for storing movie and showtime information
- ES Modules for JavaScript imports and exports

---

## 🚀 Features

- 🎬 Get all available movies
- 🔎 Get a movie by its ID
- 🕐 Get showtimes for a specific movie
- 📡 RESTful API architecture
- 📁 Organized project structure
- ⚡ Fast and lightweight Express.js server
- 🔄 JSON-based request and response handling
- 🧩 Modular controller and routing system
