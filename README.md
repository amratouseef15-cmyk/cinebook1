# 🎬 CineBook Genre API

CineBook Genre API is a backend application developed using Node.js and Express.js following the MVC (Model-View-Controller) architecture. The project provides genre management functionality for a movie application through RESTful API endpoints.

The API allows users to:

- View all available genres
- Retrieve a genre by its unique ID
- Add new genres to the collection

This project was created as part of the CineBook Genre API Challenge to demonstrate REST API development, route handling, controller logic, and proper MVC project organization.
