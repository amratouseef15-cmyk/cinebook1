# CineBook – Genre API 🎬

CineBook is an Express.js REST API that manages movie genres using the MVC architecture.

## Features

- Get all genres
- Get a genre by ID
- Add a new genre
- Store genre data with classic movies
- MVC-based project structure

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/genres` | Get all genres |
| GET | `/api/genres/:id` | Get genre by ID |
| POST | `/api/genres` | Add a new genre |

## Technologies

- Node.js
- Express.js
- JavaScript
- REST API
- MVC Architecture
